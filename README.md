# nook.

*your pocket sanctuary.*

A private, offline-first web application designed for gentle emotional regulation, low sensory load, and zero performance pressure. Built for the **RevenueCat Shipaton 2026** submission.

---

## Core Principles

- **Minimalist Aesthetic**: A quiet charcoal obsidian canvas, restrained motion, and purposeful typography designed to eliminate cognitive clutter and visual overwhelm.
- **Neurodivergent-Friendly**: Built to respect sensory sensitivities, avoid dopamine-trap loops, and provide grounding tactile anchors without overstimulating audio or visuals.
- **True Privacy**: Client-side only. Zero accounts, zero tracking, and zero external database dependencies.
- **Unpressured Flow**: No gamification, daily streaks, badges, or unsolicited notifications—open it only when you need it.

---

## Included Tools

- **Ripple & Flow**: Fluid tactile and visual anchors for gentle focus redirection.
- **Sensory Tune-Down**: Soft breathing guides and ambient focus companions.
- **Brain Dump & Reflections**: Lightweight local journaling that lives purely on your device.

---

## Stack & Architecture

- **React + Vite**
- **Tailwind CSS**
- **Monetization**: Integrated with **RevenueCat Web SDK**
- **Progressive Web App (PWA) / Offline-First**
